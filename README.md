## 📈 Engineering Philosophy

> **Don't just apply AI to engineering problems. Understand the engineering problem first.**

My approach is:

```text
Engineering Problem
        ↓
Physical Understanding
        ↓
Data / Mathematical Model
        ↓
Feature Engineering
        ↓
ML / Control Algorithm
        ↓
Simulation & Validation
        ↓
Real-World Application
```

The goal is to combine **electrical engineering fundamentals** with **modern computational methods**, rather than treating machine learning as a black box.
